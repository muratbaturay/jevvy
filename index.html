    01 · The Control Plane

    Separate judgment from execution

    One loop, two jobs. Decide cheap. Generate when it counts.

    Two layers, one gate

    Decision layer · Jev

    • Answers bounded questionsYes or no. One of five. A score from 0 to 1. Questions with an answer space you wrote down in advance.
    • Returns a typed answer with a probabilityNot a paragraph that happens to contain a verdict. A value your code can branch on, and a number saying how sure.
    • Flags low confidenceUnder your threshold it says so instead of bluffing. That is what calibration is for.
    • Never writes textNo prose, no summaries, no explanations. If the job is to write, it is not this layer's job.

    Policy
    gate

    • Threshold per decision type
    • Allowed tools and scope
    • Below threshold: fall back to Claude

    Execution layer · Claude Code

    • Reads the repositoryFinds the files, understands the code, builds the context the decision was made from.
    • Generates the review, the fix, the docUnbounded output is what a language model is for. This part never moves.
    • Runs tools and testsExecutes commands, linters, and test suites, and captures what came back.
    • Returns the changed artifactA diff, an updated file, a report. Something a verifier can inspect.

    From request to verified result

    The classifier answers. The gate authorizes. The tool executes.

    • Jev answers what you asked
    • The gate decides what's allowed
    • Claude Code does it within bounds
